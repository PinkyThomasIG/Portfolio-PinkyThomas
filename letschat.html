Let's Chat! Project

Let's Chat! is a mobile chat application built using React Native, Expo, and Firebase. It allows users to send text messages, images, and share their location in real-time, with offline support for message storage.

Project Objective

The goal of Let's Chat! is to provide a seamless chat experience with the following features:

  • Anonymous login
  • Real-time messaging
  • Offline message storage
  • Sending images and location sharing

Technologies Used

  • React Native - A framework for cross-platform mobile development
  • Expo - A platform for making universal native apps
  • Firebase Firestore - A real-time cloud database
  • Gifted Chat - A library for chat UI components
  • AsyncStorage - Local storage for offline functionality
